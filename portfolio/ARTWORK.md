# Portfolio artwork

These assets were generated with the built-in ImageGen tool for the selected editorial design. They illustrate the subject of a project; they are not screenshots, benchmark evidence, or claims about a deployed product.

| Asset                              | Purpose                                      | Prompt direction                                                                                                                                                     |
| ---------------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dist/assets/chrome-knot.png`      | Transparent fallback for the real WebGL hero | Smooth polished chrome trefoil knot, fluid tubing, studio reflections, small vermilion reflections, transparent background, no text or facets.                       |
| `dist/assets/zeno-voice.png`       | ZENO project artwork                         | Graphite background, fine silver and vermilion sound waves around a translucent sphere, cinematic scientific editorial treatment, no text or interface.              |
| `dist/assets/signspeak-vision.png` | SignSpeak ASL project artwork                | Realistic translucent open hand, five fingers, red joint landmarks and connections, softly blurred second hand, dark graphite background, no text or fake interface. |

The interactive hero uses a Three.js torus-knot mesh with a physical chrome material and environment lighting. It responds to pointer movement, includes subtle idle motion, and honors the page's pause control and reduced-motion preference.
