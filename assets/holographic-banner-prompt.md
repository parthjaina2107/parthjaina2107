# Holographic banner

Created with the built-in image generation tool using the user's `download.jpg` as a visual reference. Output: `holographic-banner.png`.

## Prompt

Use case: stylized-concept. Create a panoramic GitHub README banner closely inspired by the attached reference photo. Reference is a macro photograph-like abstract black liquid surface with delicate holographic iridescent ripples, rainbow prismatic glints and scattered tiny light particles. Recompose into a 3:1 horizontal wide banner. Near-black background, transparent glassy fine wave filaments in electric blue, violet and cyan, sparse jewel-like green magenta orange and gold spectral sparkles; a flowing luminous current meanders across the lower-middle of the frame, with dark pools and breathing room above. Soft optical bloom, shallow depth of field, a mixture of pin-sharp tiny star glints and dreamy bokeh, subtle film grain, rich inky blacks. Match the reference's delicate light-on-water optical aesthetic. No planets, no solid rainbow paint ribbons, no fiery nebula, no words, letters, logo, watermark, border or UI. Artwork only.
